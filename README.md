# Harleen & Akashdeep — Mobile Invitation V4

A mobile-first animated engagement invitation.

## Files
- `index.html` — page structure
- `style.css` — phone-first envelope, animation and invitation styling
- `script.js` — opening/replay interaction
- `assets/invite.jpg` — the invitation artwork

## GitHub Pages
1. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the root of your repository.
2. Create/open the `assets` folder and upload `invite.jpg` inside it.
3. GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Important
The image path must remain exactly:
`assets/invite.jpg`

The layout is designed for phone screens first, including iPhone Safari and Android Chrome.
